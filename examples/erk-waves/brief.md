# Talk Brief

## Audience
Soft-matter / biophysics researchers (mixed experiment + theory).

## Duration
12 min talk + 3 min discussion (~12 content slides).

## Goal — what should they remember?
1. ERK waves are organized by mechanics, not chemistry alone.
2. A two-variable feedback model with zero fitted parameters reproduces the data.
3. The model predicts a fixed phase lead that experiments confirm.

## Style
- figure first, one main message per slide
- minimal text, no bullet walls
- equations only when they help reasoning

## Constraints
- Background <= 3 slides
- Main results >= 60% of the talk
- Conclusion <= 2 slides

## Language
English.
